🚀 Démarrage rapide

CuniWorld est une application de gestion d'élevage de lapins conçue pour les éleveurs professionnels et amateurs. Elle fonctionne 100 % hors-ligne — vos données restent sur votre appareil — avec une synchronisation cloud optionnelle pour travailler à plusieurs.

Offline-first : l'application fonctionne sans connexion internet. Toutes les données sont sauvegardées dans le navigateur. Le cloud est un bonus, pas une obligation.

5 premières étapes

  1. Allez dans Bâtiments et configurez vos bâtiments et loges (ou utilisez la ⚡ Config. rapide).
  2. Allez dans Mes Lapins et créez chacun de vos animaux avec leur cage, sexe et race.
  3. Ajoutez les événements passés importants (saillies en cours, vaccins à renouveler).
  4. Revenez au Tableau de bord — les alertes et actions prioritaires apparaissent automatiquement.
  5. Faites votre première Tournée du jour pour valider eau, nourriture et nettoyage.

Deux modes de fonctionnement

🖥️ Mode local

Pas de compte requis. Données stockées dans le navigateur. Idéal pour un éleveur seul. Export JSON pour sauvegarder.

☁️ Mode cloud

Compte gratuit requis. Données synchronisées sur tous vos appareils. Permet d'inviter des collaborateurs à rejoindre votre ferme.

🐇 Mes Lapins

Le cœur de l'application. Chaque lapin est une fiche complète avec son historique complet.

Créer un lapin

Cliquez sur + Nouveau lapin (bouton en haut à droite, ou touche N). Renseignez :

  • Code — généré automatiquement (CW-F001, CW-M002…). Modifiable.
  • Nom — optionnel. Les noms sont tirés d'un pool de noms de personnages Naruto pour rester uniques.
  • Sexe — Femelle (F), Mâle (M), ou Inconnu (U).
  • Race — ex : Néo-zélandais, Rex, Californien.
  • Date de naissance — détermine l'âge et le stade (lapereau / jeune / adulte).
  • Cage / Loge — sélecteur parmi vos loges configurées (ou texte libre si pas de bâtiments).
  • Poids initial — optionnel, créé comme premier événement de pesée.
  • Disponibilité reproduction — Auto (calculée), Forcé disponible, ou Forcé indisponible.

Statuts

✅ Actif

Animal présent dans l'élevage.

💰 Vendu

Animal cédé. Reste dans l'historique.

💀 Mort

Animal décédé. Tracé pour la mortalité.

Fiche détaillée

Cliquez sur un lapin dans la liste pour ouvrir sa fiche. Elle contient :

  • Infos de base — race, naissance, âge, stade, cage, statut.
  • Reproduction — statut de disponibilité, raison, date disponible.
  • Gestation — si enceinte : mâle, date de terme, jours restants.
  • Descendance — lapereaux actifs, portées, fratrie.
  • Généalogie — mère, père, avec liens cliquables.
  • Poids — courbe d'évolution avec graphique SVG.
  • Photos — galerie chronologique, photo de profil.
  • Événements — historique complet de tous les événements.

Recherche et filtres

La barre de recherche filtre par code, nom, race ou cage. Les filtres Sexe et Statut permettent d'affiner la liste. Les lapins inactifs (vendus, morts) sont masqués par défaut — changez le filtre Statut pour les voir.

📅 Événements

Tout ce qui arrive à un lapin est enregistré comme événement. L'historique est permanent et traçable.

Types d'événements

💕Saillie — Accouplement avec un mâle sélectionné. Déclenche le calcul de gestation (terme prévu J+28).
🐣Mise-bas — Enregistre nés total, vivants, morts. Crée automatiquement les lapereaux avec filiation.
🔓Sevrage — Sèvre la portée. Crée un lot avec cage de destination. Les lapereaux changent de statut.
💉Vaccin — Produit, dose, prochain rappel. Alerte automatique à l'approche de la date.
💊Traitement — Vermifuge, antibiotique, etc. Même suivi que le vaccin.
⚖️Pesée — Poids en kg + photo optionnelle. Alimente la courbe de croissance.
💰Vente — Marque le lapin comme vendu.
💀Décès — Marque le lapin comme mort.
📝Autre — Note libre pour tout autre événement.

Cycle de reproduction

Flux optimal : Saillie → attendre 28 jours → Mise-bas → attendre 28-35 jours → Sevrage → Lot créé automatiquement.

Le tableau de bord calcule automatiquement les dates et vous alerte à chaque étape clé : saillie possible, terme proche, sevrage en retard.

📦 Lots & Jeunes

Un lot regroupe les lapereaux d'une même portée après le sevrage. Il permet de suivre la destinée d'un groupe (engraissement, vente, sélection).

Création automatique

Quand vous enregistrez un sevrage avec une cage de destination, un lot est créé automatiquement avec tous les lapereaux de la portée.

Informations d'un lot

  • Mère, père, date de sevrage
  • Nombre de lapereaux, poids moyen
  • Cage de destination
  • Liste des individus avec liens vers leur fiche

Statuts d'un lot

🟡 En cours

Lapereaux en élevage.

✅ Vendu

Lot cédé.

⬜ Terminé

Cycle terminé (intégration cheptel, etc.).

🌳 Généalogie 3D

Visualisation interactive de l'arbre généalogique complet de votre élevage en pseudo-3D.

Navigation

  • Glisser — déplacer le graphe
  • Molette / pincer — zoomer/dézoomer
  • Clic simple — ouvrir la carte de détail d'un lapin
  • Double-clic — mettre ce lapin en focus (centre le graphe sur lui et ses descendants directs)
  • Touche F — changer de lapin en focus
  • Touche Échap — quitter le mode focus

Carte de détail

Un panneau latéral affiche les infos du lapin sélectionné : photo, race, cage, statut reproduction, poids actuel. Cliquez sur le code pour aller à la fiche complète.

Utilisation avancée : utilisez le mode focus pour identifier rapidement les liens de parenté et éviter la consanguinité. Deux lapins partageant un ancêtre commun sur moins de 3 générations ne devraient pas être accouplés.

Recherche

La barre de recherche filtre les nœuds visibles par code, nom ou cage. Les résultats sont mis en évidence dans le graphe.

🏗️ Bâtiments & Loges

Représentation numérique de votre infrastructure physique. Chaque bâtiment contient des loges identifiées par un code unique (A1, B3, C10…).

Créer un bâtiment

Cliquez sur + Bâtiment et renseignez :

  • Lettre — identifiant du bâtiment (A, B, C…). Unique.
  • Nombre de loges — total de loges dans ce bâtiment.
  • Loges par rangée — pour la disposition visuelle (0 = une seule rangée).
  • Intervalle d'inspection (jours) — alerte si une loge dépasse cet intervalle sans inspection.
  • Notes — informations libres sur le bâtiment.

Configuration rapide ⚡

Entrez votre configuration en une seule zone de texte, une ligne par bâtiment :

A:10:5
B:5:0
C:8:4

Format : LETTRE:nb_loges:loges_par_rangée

Grille visuelle

Chaque bâtiment affiche une grille de ses loges. La couleur indique l'état :

Occupée (lapin présent) Défaut signalé Inspection en retard Vide

Détail d'une loge

Cliquez sur une cellule pour ouvrir la fiche de la loge :

  • Lapins actuels — animaux présents avec leurs infos
  • Historique — tous les lapins qui y ont séjourné
  • Défauts — problèmes signalés avec leur statut
  • Entretien — historique des inspections, nettoyages, réparations
  • Notes — remarques libres sur la loge

Événements de loge

🔍 Inspection

Visite de contrôle. Réinitialise le compteur d'intervalle.

🧹 Nettoyage

Nettoyage de la loge. Compte aussi comme inspection.

🔧 Réparation

Intervention technique.

💧 Désinfection

Traitement sanitaire complet.

Signaler un défaut

Un défaut peut être signalé sur une loge ou un bâtiment entier. Niveaux de sévérité : Mineur (jaune) ou Majeur (rouge). Les défauts ouverts apparaissent dans le badge de navigation et dans les Actions prioritaires du tableau de bord.

Migration automatique : si vous aviez des lapins avec des codes cage (A1, B3…) avant de configurer les bâtiments, l'application crée automatiquement les bâtiments correspondants au premier démarrage.

🏪 Magasin

Gestion des stocks de votre élevage : aliments, médicaments, équipements, et fournitures diverses.

Ajouter un article

Cliquez sur + Ajouter article et renseignez :

  • Nom — ex : Granulés lapin adulte, Ivermectine, Seringues
  • Catégorie — Aliment, Médicament, Équipement, Autre
  • Quantité initiale et unité (kg, L, pcs…)
  • Stock minimal — alerte si la quantité descend en dessous
  • Notes — fournisseur, dosage, remarques

Mouvements de stock

📥 Entrée

Réception de marchandise. Augmente la quantité.

📤 Sortie

Consommation ou utilisation. Diminue la quantité.

🔧 Ajustement

Correction manuelle (inventaire physique).

Alertes de stock bas

Si la quantité d'un article est inférieure ou égale au stock minimal, une alerte orange apparaît en haut du magasin et un badge rouge s'affiche sur l'icône de navigation.

📋 Tournée du jour

Enregistrement quotidien des soins de base : eau, nourriture par lapin, nettoyage. Accessible depuis le panneau Actions.

Comment faire sa tournée

  1. Ouvrez Actions → Tournée du jour.
  2. Cochez Eau reçue si vous avez fourni de l'eau.
  3. Cochez Nettoyage fait si les cages ont été nettoyées.
  4. Pour chaque lapin actif, sélectionnez la portion donnée : Aucune, Petit, Moyen, ou Full.
  5. Utilisez les boutons Appliquer à tous pour aller vite.
  6. Validez. La tournée est sauvegardée avec la date du jour.
Une seule tournée par jour est conservée. Si vous rouvrez la tournée du même jour, vous modifiez la tournée existante.

Les lapins sont affichés dans l'ordre des cages (A1, A2… B1, B2…) pour correspondre à l'ordre physique de votre élevage.

📈 Statistiques globales

Vue d'ensemble chiffrée de votre élevage. Toutes les stats sont calculées à partir de vos données réelles.

KPIs cheptel

Total lapins, actifs, mâles, femelles, morts. Taux de mortalité global.

Mises-bas / mois

Graphique barres des portées par mois sur les 12 derniers mois.

Meilleures reproductrices

Top 5 femelles par nombre de portées réussies.

Mortalité par race

Taux de mortalité calculé par race pour identifier les races fragiles.

Gain moyen / portée

GDQ moyen des lapereaux de chaque femelle (poids semaine 1 vs semaine 4).

Couverture pesée

% de lapins actifs ayant une pesée récente (≤7 jours).

⚙️ Actions & Données

Toutes les opérations sur les données de l'application.

Export & Import

⬇ Export JSON

Sauvegarde complète de votre élevage dans un fichier .json. Contient lapins, événements, lots, stock, bâtiments. Faites un export régulier comme sauvegarde externe.

⬆ Import JSON

Restaure depuis un fichier JSON exporté précédemment. Une sauvegarde automatique est créée avant l'import.

🧾 Export CSV

Exporte lapins ou événements au format CSV, compatible Excel et Google Sheets.

Sauvegardes locales

L'application conserve automatiquement jusqu'à 5 sauvegardes de votre état (avant chaque reset ou import). Vous pouvez restaurer n'importe quelle sauvegarde ou l'exporter en JSON.

Réinitialisation

⚠️ Attention : la réinitialisation supprime toutes vos données lapins et événements. Une sauvegarde automatique est créée avant, mais préférez faire un export JSON manuellement d'abord.

Notifications push

Activez les notifications pour recevoir des alertes sur votre appareil même quand l'application est fermée :

  • Mise-bas imminente ou en retard
  • Sevrage en retard
  • Vaccin / traitement à renouveler
  • Loges en retard d'inspection

Synchronisation cloud

Si vous utilisez le mode cloud et que des opérations ont échoué (pas de connexion), elles sont mises en file d'attente. Cliquez sur Réessayer la synchronisation pour les rejouer quand la connexion est rétablie.

Guide interactif

Le mode Guide pas-à-pas vous accompagne pour votre première configuration. Activez-le via le toggle dans ce panneau.

☁️ Mode cloud collaboratif

Travaillez à plusieurs sur la même ferme depuis différents appareils.

Créer un compte

Entrez votre email et un mot de passe. Si la confirmation email est activée, vérifiez votre boîte avant de vous connecter.

Créer une ferme

Après connexion, créez votre ferme et donnez-lui un nom. Vos données locales peuvent être migrées vers le cloud à cette étape.

Inviter des collaborateurs

  1. Cliquez sur le nom de votre ferme dans la barre du haut.
  2. Le message d'invitation est copié dans votre presse-papier.
  3. Collez-le dans un email ou WhatsApp.
  4. Le destinataire clique sur le lien, crée un compte (ou se connecte) et rejoint automatiquement votre ferme.

Synchronisation temps réel

Toute modification faite par un membre de la ferme est visible en temps réel chez les autres membres connectés (lapins, événements, photos). Les données de bâtiments, stock, tournées et lots restent locales sur chaque appareil.

Offline-first : si vous perdez la connexion, continuez à travailler normalement. Les modifications seront synchronisées automatiquement au retour de la connexion.

Changer de ferme

Cliquez sur votre avatar en haut à droite → Changer de ferme. Vous pouvez appartenir à plusieurs fermes.

💡 Astuces pro

Nomenclature des cages

Utilisez toujours le format LETTRE + CHIFFRE (A1, B3, C10). La lettre identifie le bâtiment, le chiffre la loge. Cette convention est reconnue partout dans l'application pour trier, filtrer et associer.

Optimiser la pesée assistée

La pesée assistée (Actions → Prise de poids) liste tous les lapins en attente de pesée, triés par cage. Préparez votre balance et parcourez les fiches dans l'ordre — ça correspond à l'ordre physique de vos rangées.

Éviter la consanguinité

Avant une saillie, vérifiez en Généalogie 3D que la femelle et le mâle n'ont pas d'ancêtre commun dans les 3 dernières générations. Utilisez le mode focus sur l'un, puis cherchez l'autre dans le graphe.

Sauvegarde régulière

En mode local, exportez un JSON chaque semaine. Stockez-le dans Google Drive ou votre email. Les sauvegardes automatiques de l'application sont utiles pour annuler une erreur, pas pour remplacer une vraie sauvegarde externe.

Ajouter au bureau (PWA)

CuniWorld est une Progressive Web App. Sur mobile, votre navigateur vous proposera d'ajouter l'application à l'écran d'accueil — elle se comportera alors comme une app native, avec accès hors-ligne.

  • Chrome / Android : menu ⋮ → Ajouter à l'écran d'accueil
  • Safari / iPhone : bouton Partager → Sur l'écran d'accueil

Données des photos

Les photos sont compressées automatiquement et stockées dans le navigateur (IndexedDB). En mode cloud, elles sont aussi uploadées sur le serveur. Si vous changez de navigateur, les photos locales ne seront pas transférées — seules les photos cloud sont accessibles depuis un autre appareil.
